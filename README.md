# 🌱 일쩜오도 재고현황 관리 시스템 (Iljeomodo Inventory Management)

**개미창고(3PL) · 쿠팡 물류센터 · 쿠팡외 통합 매출**의 분산된 데이터를 단일 화면에 통합하여 품절을 방지하고 수입 발주 리드타임을 사전에 관리하는 스마트 재고 운영 대시보드입니다.

---

## 🎯 주요 기능 및 특징

1. **44대 일쩜오도 마스터 상품 통합 매핑**
   - 수입(17종), 사입(27종) 전 제품의 개미창고 상품코드 및 쿠팡 윙 다중 옵션 ID를 1:N으로 자동 매핑
2. **수입 제품 100일 발주 리드타임 알림 (🚢 100일 주의)**
   - 해외 발주~통관~입고까지의 100일 리드타임을 고려하여, 소진 예상일(DOC) 100일 이하 도래 시 보라색 배지 및 즉각 필터링 지원
3. **B2B 대용량 묶음 및 선물세트 실물 재고 연동**
   - B2B 상품(`S100005`, `S100009` 등 12개입) 및 기프트세트(`S200018`, `S200019` 2병 세트)는 단품 실물 창고 재고와 100% 실시간 일치
   - 주문 발생 시 배수만큼 실물 출고량으로 자동 환산되며, 소진일(DOC)은 개별 판매 속도에 맞추어 독립 산출
4. **드래그 앤 드롭 파일 업데이트 (원클릭 파싱)**
   - 개미창고 상품목록 CSV, 쿠팡 재고건전성 CSV, 스마트스토어 등 쿠팡외 매출 CSV를 브라우저에 끌어놓는 즉시 데이터 갱신
5. **사용자 맞춤형 열/행 이동 UI (Drag & Drop)**
   - 원하는 분석 순서대로 테이블 컬럼 및 행의 순서를 드래그하여 자유롭게 변경 가능 (브라우저 로컬 저장)
6. **실물 기준 하단 합계란 및 엑셀 다운로드**
   - 세트 상품의 중복 계산을 방지한 순수 창고 실물 기준 총 재고량 및 총 출고량 집계
   - UTF-8 BOM 인코딩을 적용한 한글 깨짐 없는 통합 리포트 CSV 내보내기 지원
7. **구글 사이트(Google Sites) iframe 임베드 완벽 지원**
   - 내장된 Cloudflare HTTPS 보안 터널을 통해 고유 웹 주소를 자동 생성하며, CSP 및 X-Frame-Options 헤더를 적용하여 구글 사이트 내에서 부드럽게 작동

## 🚀 빠른 시작 가이드 (로컬 실행)

### 1. 사전 요구사항
* Python 3.10 이상
* 패키지 설치:
```bash
pip install -r requirements.txt
```

### 2. 서버 실행
바탕화면의 `run.bat`을 더블 클릭하거나 명령 프롬프트에서 아래 명령을 실행합니다:
```bash
python app.py
```
* 서버가 시작되면 브라우저에서 자동으로 `http://127.0.0.1:5000` 화면이 열립니다.

## 🌐 구글 사이트(Google Sites) 연동 방법

사내 팀원들이 개인 PC 프로그램 설치 없이 구글 사이트에서 즉시 사용할 수 있도록 연동할 수 있습니다:

1. **로컬 실행 후 보안 HTTPS 주소 확인**
   - `run.bat`을 실행하면 대시보드 상단 배너에 다음과 같은 전용 HTTPS 주소가 발급됩니다:
     > `https://xxxx-xxxx.trycloudflare.com`
2. **구글 사이트 편집기 열기**
   - 회사 구글 사이트(Google Sites) 편집 화면으로 이동합니다.
3. **임베드(삽입) 위젯 추가**
   - 우측 메뉴에서 **[삽입]** $\rightarrow$ **[URL로 삽입]**을 선택합니다.
   - 복사한 `https://xxxx.trycloudflare.com` 주소를 입력하고 **[삽입]**을 클릭합니다.
4. **크기 조절 및 게시**
   - 삽입된 위젯의 너비와 높이를 대시보드가 한눈에 보이도록 넓게 조정한 뒤 **[게시]** 버튼을 누릅니다.
